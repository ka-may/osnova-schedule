# Расписание «Основа» — демо-прототип

Кликабельный прототип приложения расписания музыкальной школы. Все данные вымышленные.

- **Расписание школы** — открыто без входа: филиал, день (30 дней вперёд), шаг ½ ч / 1 ч, масштаб −/+ (на телефоне — щипком), нажатие на класс — только этот класс.
- **Моё расписание** — «Войти», логин `admin`, пароль `admin`: свои занятия и остаток абонементов.
- **Админка** — на экране входа «Вход для администратора», тоже `admin` / `admin`; демо-ID учеников: 184523, 187340, 190118.

Один файл `index.html`, без сборки. Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
